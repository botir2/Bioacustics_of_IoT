Audio PCA Trajectory Visualiser – Project Continuation Notes

Project goal
The goal of this small project is to build a Python/PyQt6 tool that visualises acoustic signals in a PCA space, similar to a protein PCA trajectory plot. Instead of protein conformations, the system uses audio features extracted from bird/no-bird recordings. The long-term idea is to create a reference acoustic map from a labelled dataset, then place new WAV files or live microphone input into that map as moving points or trajectories.

2. Single WAV PCA trajectory was created
The first version allowed the user to load a single WAV file. The program:
- loaded the WAV using librosa
- split the audio into windows
- extracted audio features from each window
- applied PCA to reduce the features to PC1 and PC2
- animated the trajectory on the plot

The features extracted from each audio window were:
- RMS energy
- zero-crossing rate
- spectral centroid
- spectral bandwidth
- MFCC mean values

Later, spectral rolloff was also added to make the feature vector match the dataset feature map.

4. Dataset feature-map builder was created
A second script called build_feature_map.py was created.

Its purpose is to process the warblrb10k dataset once and save extracted features into a CSV file, so the system does not need to reprocess all WAV files every time.

The output file is:

data\warblrb10k\features_map.csv

The feature map CSV stores:
- itemid
- label
- f0, f1, f2, ..., f17

Each row represents one audio file converted into an audio feature vector.

5. Multiprocessing was added
The first version of build_feature_map.py processed audio files one by one, which was slow.

It was then rewritten using Python multiprocessing so multiple audio files can be processed in parallel using CPU cores.

This made dataset feature extraction faster.

Current meaning of the map
The saved map is not a deep learning model. It is a feature-based acoustic map.

Workflow:
Dataset WAV files
→ feature extraction
→ saved feature map CSV
→ StandardScaler
→ PCA
→ 2D acoustic map

In this map:
- bird audio should tend to fall near bird-labelled regions
- no-bird/background audio should tend to fall near no-bird-labelled regions
- a new WAV file can be transformed into the same PCA space and shown as a moving trajectory

Important concept
PCA is not a classifier by itself. It is an unsupervised dimensionality reduction method.

Current system:
- visualises acoustic behaviour
- shows where an audio signal falls in the PCA feature space
- can support later classification or routing logic

Current interpretation:
- label = 1 means bird present
- label = 0 means no bird / background
- a moving dot or trajectory shows the current audio window sequence in the PCA map
